# Source Movement for Viewpoint

A Project Zomboid (build 42.21) mod that adds Source engine style movement to
[Viewpoint](https://steamcommunity.com/sharedfiles/filedetails/?id=3809306528)'s first-person view. 
Loaded by [ZombieBuddy](https://steamcommunity.com/sharedfiles/filedetails/?id=3619862853).

## Features

- Jumping.
- Bunny hopping.
- Standing on fences, rails, car roofs, and props.
- Trimping off slopes.
- Jump through open or broken windows, or crash through closed ones with enough speed.
- Jumping over water.
- Zombie groups can grab and take down airborne players.
- Multiplayer Support

## Requirements

- ZombieBuddy
- Viewpoint
